# Requirements

기능적 요구사항

1. 사용자가 검색어를 입력하면 추천어 목록을 보여줘야한다.
2. 추천어는 입력값이 바뀔 때마다 업데이트 되어야 한다.
3. 추천어를 클릭하면 해당 검색어로 검색을 한다.
4. 키보드 위 아래 버튼으로 추천어를 이동할 수 있어야한다.
5. Enter 를 누르면 현재 선택된 추천어 또는 입력값으로 검색할 수 있어야한다.
6. ESC를 누르면추천어 목록을 닫는다.
7. 검색어가 너무 짧으면 추천어를 보여주지 않는다.

비기능적 요구사항
1. 추천어는 빠르게 보여야 한다. (얼마나 빠른 건지 계산할 수 있어야 한다.)
2. API 호출을 과도하게 보내면 안 된다.
3. 느린 네트워크에서도 잘 동작해야함. 
	- [] 시간 대략 
4. 모바일과 데스크탑 모두 지원
5. 접근성
6. API 실패 시에도 검색창 자체는 계속 사용할 수 있어야함



Frontend가 무엇을 책임지고 Server가 무엇을 책임지는 지를 분리하는 것이 API 설계시에 핵심이다.
